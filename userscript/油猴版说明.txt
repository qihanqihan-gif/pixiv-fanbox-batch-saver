画师文件夹下载器 · 油猴版 v0.2.3
============================================================
文件：文件夹下载器-油猴版.user.js（3819 行，LF/UTF-8 无 BOM）
用例：本地回归用例全部通过（收藏线、续传、分块边界、界面结构等）

一、装法
------------------------------------------------------------
1. 桌面 Chrome/Edge 装 Tampermonkey（手机端的篡改猴也能装，但写盘依赖
   File System Access API，能不能用要看浏览器内核，见第五节）
2. 打开 Tampermonkey 面板 → 添加新脚本 → 把本文件内容整体粘进去 → Ctrl+S
   或直接把 .user.js 拖进浏览器窗口，Tampermonkey 会弹安装页
3. 打开任一 fanbox / pixiv 页面，右下角出现「📁」圆钮，点开就是面板

   手机本机安装（实测可用）：手机浏览器打不开 file:// 的 .user.js，
   用 `adb reverse tcp:8765 tcp:8765` + 电脑起一个静态服务，手机访问
   `http://127.0.0.1:8765/ffdl.user.js`，篡改猴会自己拦下来弹安装/更新页。

二、这一版有什么
------------------------------------------------------------
· 三种模式（和扩展版 v0.3.38 对齐）：
    1) FANBOX 画师  填 creatorId 或主页链接
    2) PIXIV  画师  填画师 uid 或主页链接
    3) PIXIV  收藏  账号框留空 = 当前登录账号；填数字 uid = 那个账号的公开收藏
· 收藏落点两种：
    · 平铺：<你选的目录>/_我的收藏 (PIXIV)/<日期-作品id-标题>/
    · 分组：<你选的目录>/_我的收藏 (PIXIV)/<画师名> (PIXIV)/<日期-作品id-标题>/
            组按件数从多到少排；作者被抹成 "-----" 的归「_未标注作者」
· 收藏枚举：插画/漫画（illusts/bookmarks）+ 小说（novels/bookmarks）分页拉全量，
  按 id 去重；跑完把整份清单记进本地账本，键 `posts:pixiv:fav:<uid>`
  （**在「最多篇数」截断之前写**，换机才不会永久漏篇）
· 导出 / 导入枚举 JSON：收藏模式导出 `pixiv_收藏_<uid>_<n>篇.json`
· 断点续传：Range 分块（每块 6 MB）+ 定位写 + `_半截.json` 台账 + 60 秒看门狗；
  服务器不吃 Range（回 200）时自动从头整包写。油猴拿不到响应流，所以「续传」是
  「按区间重发」，不是扩展版那种单连接流式写盘
· 目录约定与扩展版一致：` (FANBOX)` / ` (PIXIV)` 后缀、`_站点.json`、
  `_清单.jsonl` / `_索引.csv` / `_进度.json` / `_完成篇.jsonl` / `_失败清单.json`

三、0.2.2 / 0.2.3 修的是什么（两轮真机冒烟的结果）
------------------------------------------------------------
0.2.2（第一轮）：
· 数字行四个框被挤成 18px、第 4 个跑出屏 → 固定 76px，拆成两行
· 收藏模式会静默沿用输入框里残留的画师 uid（会把该 uid 的公开收藏
  当成「我的收藏」）→ 开跑前显式提示是哪个 uid
· 收藏里被屏蔽的条目（作者被抹成 "-----"）分组时全归一组并报数
· 页面刚加载就点「开始」会误报「请先选择保存文件夹」→ 先补一次句柄恢复
· 分块下载：区间响应比请求短、又没到总长时改为失败重试，不再静默留短文件
· 平铺收藏的 `_站点.json` 不再把首件作品的作者当画师名
· 「已写清单」不再一轮打两遍

0.2.3（第二轮：小说 / 导出 / 预检 / 暂停 / 分组落盘）：
· **导出清单在油猴沙箱里必然失败**（`Illegal invocation`）→ 改从 unsafeWindow 调，
  真机现在会正常弹出系统保存框；万一不可用就退回写进所选目录
· 收藏里作者被抹成 `-----` 的条目不再建出「----- (PIXIV)/」，统一归「_未标注作者」；
  该组的 `_站点.json` 也写成「收藏账号 <uid>（未标注作者）」，不再残留别的画师名
· 已删除 / 转私密的收藏条目（HTTP 404）记「已失效、跳过」，不再每轮算一次失败；详情正常但页面列表 404 的另记「被拒（受限）」
· 画师文件夹一多，「开始下载」会被列表顶到视口外 → 列表 27vh→18vh + 动作行钉底

五、已知限制（别当成 bug）
------------------------------------------------------------
· 写盘用的是 File System Access API（`showDirectoryPicker`）。不支持这个 API 的
  浏览器（部分手机内核、Safari）根本没法用 —— 这不是脚本能绕的
· 收藏枚举靠 `GM_xmlhttpRequest` 带 cookie 打 `www.pixiv.net/ajax/...`；
  没有登录态就只能读「公开收藏」，填别人的 uid 也能读他公开的那份
· 每次页面刷新后目录权限回到 prompt，需要重新点一次「允许」（浏览器行为）
· 单篇模式（下载本篇）**故意不跳过**已完成的投稿（和扩展版一致）：小说这种只有
  txt 的投稿每次都会重写一遍正文，统计里也显示「新增 0 个文件」
· 脚本 @name 仍是「Fanbox/Pixiv 文件夹下载器（油猴版）」：**故意不改**，
  改了 Tampermonkey 会当成另一个脚本，原来的设置和本地账本就接不上了
· 分组模式每个组都会打印一行「限制最多 N 件」，那是全局上限；各组尾行
  「完成：新增 X」是累计值，不是本组增量
